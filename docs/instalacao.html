Guia de instalação

Como instalar o JARVIS no seu PC

Assistente de voz que ouve, fala e controla o computador. Em menos de 10 minutos ele está rodando no Windows.

Windows 10 / 11 Python 3.11 a 3.13 Microfone e caixas de som Chave Gemini gratuita
1

Instale o Python

Baixe em python.org/downloads. Use a versão 3.11, 3.12 ou 3.13. Versões mais novas ainda não são testadas.

Na primeira tela do instalador, marque "Add python.exe to PATH" antes de clicar em Install Now.

Para conferir, abra o Prompt de Comando e digite:

py --version
2

Instale o Git

Baixe em git-scm.com/download/win e instale com as opções padrão. Depois confira:

git --version
Sem Git? Dá para baixar o ZIP pelo botão verde Code → Download ZIP no GitHub e extrair numa pasta. Os próximos passos são iguais.
3

Baixe o JARVIS

No Prompt de Comando, entre na pasta onde quer guardar o projeto e clone o repositório:

cd %USERPROFILE%\Documents
git clone https://github.com/jgm-source/jarvis-opensource.git
cd jarvis-opensource
4

Rode o setup

O setup instala as dependências do Windows e o navegador usado para automação web. Leva alguns minutos.

py setup.py

Ao final aparece ✅ Setup complete!

Deu erro de versão? Você tem mais de um Python. Force a versão certa com py -3.12 setup.py (ou 3.11, 3.13).
5

Pegue sua chave Gemini (grátis)

Acesse aistudio.google.com/app/apikey, entre com a conta Google e clique em Create API key. Copie a chave.

Guarde como senha. Nunca mostre a chave em vídeo, print ou no GitHub. Se vazar, apague no mesmo site e gere outra.
6

Abra o JARVIS pela primeira vez

py main.py

Vai aparecer a tela de setup. Cole a chave Gemini e confirme. A chave fica salva só no seu PC, em config/api_keys.json.

Fale com ele ou segure Ctrl + Espaço para falar. Em ⚙ → WAKE WORD você ativa o "Hey Jarvis".

7

Configure os plugins (opcional)

Em ⚙ → PLUGIN SETTINGS ficam as integrações. Cada uma pede a própria chave:

  • Groq: transcrição de voz mais rápida. Chave grátis em console.groq.com.
  • Trello: quadros, listas e cartões por voz.
  • Rastracking: rastreio de pedidos por voz.
  • Brain: qual modelo pensa as respostas (Gemini por padrão).

Sem configurar nada disso o JARVIS já funciona por completo com a chave Gemini.

8

Crie o ícone na área de trabalho

Dê dois cliques no arquivo criar-atalho-jarvis.bat dentro da pasta do projeto. Ele cria o atalho JARVIS na área de trabalho, que abre o assistente sem janela preta de terminal.

Para fixar na barra de tarefas: botão direito no atalho → Mostrar mais opções → Fixar na barra de tarefas.

9

Problemas comuns

  • ModuleNotFoundError: instale o módulo citado com py -m pip install NOME.
  • Microfone não funciona: Configurações do Windows → Privacidade → Microfone → permitir para aplicativos da área de trabalho.
  • Vídeo do YouTube não abre no HUD: rode py -m pip install -U yt-dlp.
  • Automação do navegador falhou no setup: rode py -m playwright install chromium.
  • Quer apagar tudo que ele lembra: delete o arquivo memory/long_term.json.
